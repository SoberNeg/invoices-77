# OCR Invoice Table

Прототип программы для распознавания счетов и формирования Excel-таблицы.

## Возможности

- добавление счетов PDF, XLSX и XLS;
- Drag & Drop нескольких файлов;
- счетчик загруженных счетов;
- извлечение:
  - № п/п;
  - Покупатель;
  - Поставщик;
  - Дата;
  - № счета;
  - Наименование товара;
  - Кол-во;
- поддержка нескольких реальных макетов счетов;
- OCR fallback через PaddleOCR;
- экспорт в XLSX;
- столбцы `ИТОГО` и `Остаток`;
- пустая строка после каждой товарной позиции;
- оформление Excel по рабочему образцу.

## Требования

Рекомендуется Python 3.11.

Установка зависимостей:

```bash
python3 -m pip install -r requirements.txt
```

Для проверки Drag & Drop:

```bash
python3 -c "import tkinterdnd2; print('tkinterdnd2 OK')"
```

## Запуск на macOS / Linux

```bash
python3 ocr_invoice_table.py
```

## Запуск на Windows

```powershell
python ocr_invoice_table.py
```

## Поддерживаемые форматы

- `.pdf`
- `.xlsx`
- `.xls`

## Примечание об OCR

Если PDF содержит нормальный текстовый слой, программа сначала использует PyMuPDF. OCR применяется как резервный вариант для файлов, где текстовый слой отсутствует или недостаточен.

## Репозиторий

Счета и другие рабочие документы не включаются в репозиторий автоматически. Добавляйте тестовые документы только если их допустимо хранить в GitHub.
